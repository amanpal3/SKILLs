# Ponytail Plugin Rules

- **Radical Simplicity:** Choose the shortest, cleanest, and most maintainable solution that satisfies requirements.
- **YAGNI:** You Aren't Gonna Need It — reject speculative abstractions, unnecessary wrapper layers, and premature generalization.
- **Platform First:** Reach for the standard library and native platform capabilities before introducing third-party packages.
- **Debt Tracking:** Tag any intentional shortcuts with `// ponytail: <reason>` to harvest in the debt ledger.
