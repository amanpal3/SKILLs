# CodeRabbit Plugin Rules

- **Pre-Commit Review:** Perform a full code review audit before any commit or PR.
- **Strict Quality Hierarchy:** Prioritize Correctness → Security → Readability → Performance.
- **Vulnerability Checks:** Verify input validation, authentication/authorization boundaries, and ensure no hardcoded secrets exist.
- **Actionable Fixes:** Provide concrete, minimal diffs for all identified issues.
